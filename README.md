# Лига сомнительных чемпионов

Telegram Mini App для друзей: коллекционные пиксельные карточки за повседневные подвиги. Бот: [@HeroicHeroesBot](https://t.me/HeroicHeroesBot). Исходники: [MrBoomer1981/HeroicHeroes](https://github.com/MrBoomer1981/HeroicHeroes).

## Что реализовано

- Пять карточек пяти редкостей, поиск и фильтры.
- Пустая коллекция при первом входе и короткое знакомство.
- Самостоятельное получение с историей и датой, профиль и витрина из трёх карточек.
- PNG-экспорт 1080 × 1710 с именем владельца.
- Вход через Telegram с серверной проверкой подписи и давности initData.
- Закрытый доступ по списку Telegram ID; пустой список закрывает вход всем.
- Сохранение в SQLite: коллекции пользователей изолированы и переживают перезапуск.
- Согласование изменений между устройствами: устаревшее изменение отклоняется, интерфейс загружает текущую коллекцию.
- Бот с /start, /help, /id и кнопкой запуска приложения. Существующий webhook сохраняется, запуск polling при нём отклоняется.
- Dockerfile и конфигурация Railway: один сервис, одна реплика, постоянный том /data.

## Локальная разработка

Нужен Node.js 24.14.x или новее в ветке 24. Зависимости нужны только для тестов; production-сервер использует встроенные модули Node.js.

```sh
npm ci
npm run build
npm test
npm start
```

Открыть http://127.0.0.1:4048. Локальный просмотр хранится отдельно в браузере и не переносится в Telegram. Для переменных можно скопировать `.env.example` в `.env`. Без `.env` запускается локальный просмотр, кроме окружения production/Railway.

`Открыть Лигу.command` запускает локальный сервер. После правок выполнить `npm run build`.

## Запуск в Telegram и Railway

Пошаговая инструкция: [DEPLOY_RAILWAY.md](DEPLOY_RAILWAY.md). Разработка и размещение идут по маршруту **GitHub main → Railway**.

Нужно добавить настоящий BOT_TOKEN в Variables сервиса Railway. Токен не хранится в репозитории. На первом запуске список участников может быть пуст: команда /id сообщает ID, после чего владелец добавляет его в ALLOWED_TELEGRAM_IDS.

Локальный preview не является проверкой настоящего Telegram-входа. Состояние развёртывания и реальные проверки фиксируются в инструкции размещения, а план этапов — в [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md).

## Структура

- `model.mjs` — каталог, состояние и правила получения/витрины.
- `app.source.js` — интерфейс, вход, запросы API и PNG-экспорт.
- `src/index.html`, `src/style.css` — исходная разметка и стили.
- `dist/` — собранный интерфейс и графика; JS/HTML/CSS пересобираются.
- `server/` — проверка входа, конфигурация, SQLite и HTTP API.
- `tools/server.mjs` — запуск сервера и, при RUN_BOT=true, бота.
- `tools/bot.mjs` — Telegram Bot API и long polling; отдельный `npm run bot` нужен только при RUN_BOT=false у сервера.
- `tools/*.test.mjs` — тесты модели, подписи, API, сохранения, бота и интерфейса в DOM-эмуляторе.

## Проверки и ограничения

Автотесты охватывают новый аккаунт, проверку подписи/срока входа, запрет посторонних, изоляцию пользователей, конфликт версий, сохранение после повторного открытия SQLite, правила витрины и первый сценарий интерфейса. Они не обращаются к настоящему Telegram API.

Встроенный браузер при работе над этой версией недоступен. Проверка реальной вёрстки, клавиатуры, Telegram BackButton и скачивания PNG на iOS/Android остаётся перед приглашением друзей. SQLite в Node.js 24 помечен как experimental; образ закреплён на конкретной версии Node.js.

Одна реплика обязательна: SQLite хранится на одном томе, а у бота должен быть один polling-процесс. Сессии действуют 12 часов, новые initData принимаются в течение часа; при истечении входа приложение нужно заново открыть через бота. Истории доступны владельцу аккаунта через API; публичных профилей и фото нет.

## Дизайн и материалы

Пиксельный мультяшный стиль, ограниченные палитры, спортивная подача абсурдных героев. У обычной карточки печатная рамка, у редкой — кислотная фольга, у эпической — выход мегафона за край, у легендарной герой ест рамку, секретная оформлена как кассовый чек.

«ОН НАЧАЛ» — первый шаг. «Ночной директор» — завершённая вечерняя задача, без требования не спать. «Голос района» — первое публичное выступление. «Дедлайноед» — завершённый отложенный проект. «Без лишнего» — покупки строго по списку. Редкость назначена по сюжету: случайных паков и платного получения нет. Рейтинг и характеристики шуточные.

Пять портретов созданы imagegen и сохранены в `dist/assets/{started,night,voice,deadline,receipt}.png`. Промпты — `tools/image-prompts.json`. Шрифт Press Start 2P и лицензия находятся в `dist/assets/`. В `previews/` — ранее созданные образцы экспорта, а не актуальные снимки приложения.
